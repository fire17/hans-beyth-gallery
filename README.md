# Hans (Shmuel) Beyth gallery

Historical photographs and locally preserved research material about Hans (Shmuel) Beyth, Youth Aliyah and Henrietta Szold.

Website: https://hans-beyth.akeyo.io/

German is the initial language; English and Hebrew are available. Each item identifies its origin and source. Original photographs remain the default. AI-enhanced derivatives are labelled and can be selected in the zoom viewer. Archive originals not obtained are identified in a separate pending research list.

The docs folder contains the self-contained GitHub Pages site and all current assets. The local research preview receives live updates; online updates appear after a new publication. No scheduled jobs are configured.
